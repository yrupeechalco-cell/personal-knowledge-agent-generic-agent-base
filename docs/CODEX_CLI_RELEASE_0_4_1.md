## 本次发现并修复

旧索引保存的 Windows 普通路径与文件系统返回的规范路径写法不同。直接比较会把仍在原位的文件误判为不可访问，并阻止扫描、标注或重复目录识别。

现在只在文件系统比较前解析路径，保留原资料编号与分类关联，继续检查系统链接和目录边界。原生回归用例覆盖普通路径扫描、保存标注、再次扫描保留编号与摘要，以及重复目录拒绝。

安装更新不自动重扫用户目录；旧索引记录的可用状态会在下一次用户主动扫描时刷新。本次保留原有 8 份样本资料及标注，没有扩扫已增加其他文件的目录。
