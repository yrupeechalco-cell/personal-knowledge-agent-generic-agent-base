# 文件分布图（0.3.6）

先沿用设备上的真实目录，不要求用户填写标签或建立新分类。

## 入口和操作

1. 左侧点击「文件分布图」，选择要查看的文件夹。未连接知识库时也可点击「查看文件分布图」。
2. 中间为当前文件夹，周围为真实的直接子文件夹和文件。连线只表示包含关系。
3. 点击文件夹进入下一层；上方路径和「上一级」可返回。搜索仅作用于当前目录，进入新目录时自动清空。
4. 点击文件查看位置、大小和可用预览。支持的文本与 DOCX 沿用原有只读预览；图片、音视频和其他格式显示文件信息，不承诺播放或内容分析。
5. 可切换「列表」、刷新，或「换个文件夹」。文件多时每页显示 16 个节点。

## 数据边界

- 复用已有 `list_directory_read_only` / `read_file_preview_read_only`。目录枚举只读取名称和元信息，不导入附件，不复制、移动或修改原件。
- 大文件的大小不妨碍在图上显示；正文预览仍受已有安全上限约束。
- 只显示当前层级，不递归扫描全盘、不猜测未打开子目录内的文件数。目录超过已有 1000 项枚举上限时明确提示截断。
- 符号链接和其他特殊条目不展开；现有 native 路径边界校验继续生效。
- 进入只读目录浏览时隐藏 Agent 面板，并暂停隐藏知识库的自动扫描和 AI 队列。已经发出的模型请求无法收回，但暂停后不保存其返回结果，也不启动后续任务。返回「文件知识库」后沿用此前队列设置。
- 既有卡片与分类数据保留。本版没有增加账号同步或新的文件传输。

## 验收

- 真实目录名称、文件数和路径与系统文件夹对应。
- 下钻/返回、过滤、分页、刷新后条目减少、列表切换、空目录、图片和大视频元信息。
- 点击链接条目不会读取目标；加载期间禁用重复导航。
- 在目录图停留时，隐藏资料库不自动扫描或保存 AI 分类。
- 浏览前后抽查源文件哈希和修改时间不变。
