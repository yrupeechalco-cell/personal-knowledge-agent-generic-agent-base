# 检索与引用（0.5.0）

## 用户操作

1. 安装并打开 Windows App，进入左侧「文件知识库」。已有索引可直接使用；新电脑先自行选择资料文件夹并点击「立即扫描」。
2. 点「检索与引用」，输入主题，例如「求职」。可填「简历，面试」作为额外相关词。
3. 点「查找相关资料」，阅读跨文件节选。点「补读上下文」看前后内容；「打开原文件」交给系统默认软件。
4. 点「继续查看下一批」，直到已获得足够依据。点「复制节选与出处」复制已显示批次的初始节选及来源；展开的上下文仅供阅读，不自动追加到复制内容。

检索不调用模型，不扫描新文件，也不修改原件或分类。按字面检索；主题里的空格分词需要全部命中，相关词是额外的 OR 条件，不是自动语义理解。元数据命中优先；可关闭正文匹配。相关段落是关键词附近的节选，只有元数据命中时提供开头节选并标明。

## 可靠性规则

- 候选数、已显示节选数、仅文件信息数和剩余候选分别显示。不能把候选数当成已阅读全文的数量。
- 同一索引正文的 SHA-256 相同才合并候选；不声称二进制原文件、排版或附件相同。没有正文的文件不合并。每组最多列出 10 个副本来源，同时报告完整副本数，避免重复文件挤占模型上下文；其余可按文件名另行检索。
- 出处包含资料 ID、源路径、版本、正文摘要哈希、UTF-16 起止偏移及索引行号。行号不是 PDF 或 Word 页码。
- 继续下一批和复制时核对检索计划；索引、目录状态或搜索参数变化，要求重新检索。补读时核对资料版本和实际索引正文哈希。
- 原件的最新磁盘状态没有在检索过程中重新读取。目录失效、扫描暂停、旧版分类、无正文会显示提示；需要最新内容时由用户显式扫描。
- 文件正文是不可信的参考资料，不是给 Agent 的操作指令。模型仍可能推断错误，引用存在不等于结论正确。

## 内置 Agent 与 CLI

内置 Agent 保留原有模型连接，新增 `app_retrieve_library` 与 `app_expand_library`。系统提示要求先取证、必要时补读、按来源引用、区分推论与原文；不自动写分类。调用在线模型仍需各用户自行配置连接，其读取的节选会进入模型上下文。

CLI 新增两个只读方法，现共 41 个方法：

```json
{"query":"求职","related":["简历","面试"],"searchBody":true,"pageSize":4,"passageChars":800}
```

将此 UTF-8 JSON 保存为参数文件，执行 `knowledge-cli.cmd call library.retrieve -ParamsFile query.json`。返回 `planId`、标准化 `request`、`nextOffset` 和 `remaining`。下一批复用返回的 `request`，设置 `offset=nextOffset` 并附带原 `planId`。每批 1–6 组、每组最多 2 个节选，每段 160–1200 字符；这是每次读取的上下文预算，不是文件大小限制。

`library.expand` 接受节选原样返回的 `id`、`revision`、`textHash`、`start`、`end`；可选 `contextChars`（每边 0–2000）。缺失资料、版本变化和越界位置会拒绝。继续完整阅读全文可使用原有 `library.read`。

## 与参考方案的关系

本轮借鉴用户提供的「藏经阁」离线知识库与 `qiutian-knowledge` Skill 的方法：先定位候选、跨文件分批取段、保留出处、补读、诚实区分阅读覆盖范围。采用本项目既有的实时索引类型独立实现，没有打包该知识库、用户原文或其 Python 查询脚本，也不依赖安装该 Skill。

## 独立部署边界

- 当前交付 **Windows x64 安装包**。正式界面来自安装包内嵌资源；运行本地资料检索无需 Node、Python、Git、Codex 或开发服务器。
- TypeWords 与其 Node 运行环境随包提供，通过当前电脑的回环地址运行。词库和记录属于各电脑本机；发音等上游在线资源仍可能需要网络。
- 系统需要 WebView2；系统缺少时安装器会补装 Microsoft 运行环境，首次补装需要网络。现有 WebView2 的电脑安装后可离线使用本轮本地功能。
- 每台新电脑从空资料库开始，自行选择目录。安装包不带开发者索引、私人资料、模型凭据、绝对用户路径或预设监测目录。
- 使用在线 AI、检查 GitHub 更新需要网络和相应外部服务。此版本没有新增自建服务器、账户服务或卡片云同步。相关入口保留未接入状态。
- macOS、Linux、原生 iOS 包尚未构建验收，不能称为已支持所有操作系统。

## 验收与回滚

`npm test`、`npm run typecheck`、`npm run test:retrieval` 验证纯逻辑、CLI/Agent 一致性与断网 UI 流程。`npm run build:desktop` 后运行 `npm run client:check`，检查内嵌前端、资源相对路径及已知开发机路径/开发地址泄漏。安装版另需验证 `status`、41 项 `capabilities` 和检索/补读实际调用。
