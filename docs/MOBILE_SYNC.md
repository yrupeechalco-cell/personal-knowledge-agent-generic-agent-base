# 手机知识库与电脑同步（0.3.4）

## 能做什么

手机有自己的 IndexedDB 资料库；保存成功后刷新或重新打开相同地址仍保留。可以新建 Markdown 笔记、导入 TXT/Markdown、图片、音频和视频副本，搜索文件名/正文/分类、编辑文字正文、修改摘要/分类/关键词和归档资料。图片可放大，音视频有播放器，附件可导出原文件。知识 tip 随电脑整理结果下载，可查看原文引用。归档不删除电脑原文件。

手机离线保存后，待同步修改留在本机。电脑 App 与手机页面同时打开、处于同一局域网时每 15 秒同步，也可手动同步。手机正文修改会写回电脑原文件；分类、标签和摘要写入电脑的知识索引，不移动原文件。手机新笔记写入首次开启同步时明确选择的目录，以唯一编号避免覆盖同名文件。

## 开始使用

1. 安装 0.3.4 或更新的 Windows 正式版；旧版仍能同步文字，但不能接收附件。
2. 在「文件知识库」中添加要管理的目录；这与旧的 Markdown 工作区是两个入口，只有文件知识库已收录的目录参与同步。
3. 点击左侧底部手机图标「手机同步」，开启并选择手机新笔记的保存目录。可选一个现有监测根目录或另一个独立目录。
4. iPhone 与电脑连接同一路由器/Wi-Fi，使用相机扫描二维码，选择 Safari 打开。保存或收藏这个地址。
5. 手机「同步」显示配对状态和待同步数量，列表中点击资料即可管理。

配对二维码携带授权密钥，仅给自己的设备使用。关闭电脑端同步会撤销现有密钥；重启 App 自动恢复此前明确开启的服务。若 Windows 防火墙询问入站权限，仅允许可信家庭/办公局域网的 TCP 5177。不要配置公网端口映射。

## 手机文件访问

点击「资料 → 导入」先显示知识库的文件访问说明，说明读取用途、支持范围、本机副本和配对后的同步行为。点击「暂不允许」返回，仍可新建和管理已有笔记；点击「允许并选择文件」才打开系统文件选择器。取消系统选择不导入资料，下次导入仍需选择文件。

- 图片：JPEG、PNG、GIF、WebP、HEIC/HEIF、AVIF。
- 音频：MP3、M4A、WAV、AAC、OGG。
- 视频：MP4、MOV、WebM。
- 图片、音频、视频及导入批次不设固定字节上限，以实际可用存储空间为准。文字编辑正文仍为 1 MB，资料目录最多 1500 项。
- 浏览器支持存储估算时先检查配额；HTTP 局域网等无法获取估算的环境逐块保存，以实际写入结果为准。空间不足时提示并撤销本批导入，原文件不变。电脑上传暂存与最终收件目录均检查实际磁盘空间。
- 附件按 4 MB 分块保存和传输，显示保存/上传/下载百分比。上传断线后保留已传部分，恢复连接后继续；下载未完成时需重新下载。导入时请保持页面打开，清除网站数据会移除本机副本。
- 播放取决于设备的编码支持；无法解码时保留原文件并提供导出，不静默丢弃。
- 手机导入附件会上传到电脑所选收件目录，保留文件格式。电脑已有附件在手机打开时下载，成功后保存在本机。分类只更新索引，原文件不移动或改写。
- 图片识别、音视频转写暂未接入；摘要和关键词可手动填写，原有文字资料 AI 不受影响。

这是应用内的使用说明与逐次选择流程，不是 iOS 照片权限弹窗，不记录或声称拥有整个手机/文件夹的持久权限。当前网页只读取用户选择的副本，无法扫描手机文件夹或写回手机原文件。原生 iOS 文件夹授权需后续通过系统目录选择器实现。

## 冲突与保存

- 保存按钮成功后才更新 UI 的保存状态；数据库失败会保留编辑框并提示错误。
- 两端修改同一资料时不自动覆盖，在「同步」对比手机/电脑正文、摘要和分类，选择保留手机副本（电脑原版也保留），或明确放弃手机改动。
- 电脑移除源文件或移除目录索引时，手机副本保留并提示处理，不静默删除。
- 上传期间再次编辑，新的本机编辑仍保持待同步；服务端已提交但响应丢失时通过持久操作回执识别重试。
- 不同电脑的知识库标识不能混合。多浏览器页签用 IndexedDB 事务与编辑编号防止旧页签覆盖新内容。
- 编辑过正文后，旧 tip 的引用与分析版本仍需在电脑上核对；不能把不匹配的引用保存为当前资料证据。

## 当前边界

- 这是手机 Web 管理页，不是原生 iOS App。HTTP 局域网页面无法安装 Service Worker，所以断网时可在已打开页面中编辑，但完全关闭后需重新连上电脑才能打开。后续的 HTTPS/PWA 或原生 iOS 才能补上完整离线启动。
- 没有公网中继/云端存储，不能跨路由器自动同步；iOS 关闭/挂起网页后不保证后台运行。
- HTTP 传输不加密，只适合你信任的局域网。API 需要配对密钥，并拒绝非局域网来源、跨站 Origin、非 IP Host、任意路径、非白名单接口以及超限请求。
- 同步已收录文本、知识元数据及上述图片/音视频原文件。DOCX 提取正文可阅读和分类；Word/PDF 等附件本体不缓存到手机。在线 AI 仍由电脑执行，密钥不会提供给手机。
- 手机浏览器存储属于网站数据，清除网站数据或使用无痕模式可能丢失手机副本。可以导出 JSON 资料目录备份（正文和分类，不含配对密钥及附件原文件）；附件需同步到电脑或在资料内单独导出。浏览器地址（协议/IP/端口）变化会进入不同存储空间，旧地址的待同步内容需先同步或备份。
- 电脑旧 Markdown 工作区、TypeWords 学习记录、图谱/画布布局暂不在本轮同步范围内。

## 验收步骤

使用新建的测试资料目录，避免把测试内容混入日常资料。

1. 在电脑测试目录放一份 TXT/Markdown，文件知识库添加此目录；配对手机，应看到同样正文。
2. 手机改正文、摘要、分类和关键词并保存；等待待同步数量归零。电脑重新扫描或自动刷新后应显示相同内容，资源管理器中的路径不变。
3. 电脑修改原文并保存；手机点立即同步，应收到新版。
4. 手机保持页面打开，断开 Wi-Fi，编辑并保存；恢复连接后同步，改动应到电脑；联网刷新手机后仍保留。
5. 断线期间手机和电脑分别修改同一篇，恢复后应提示冲突，两个版本都可查看。「保留手机副本」应新增一篇，电脑原版内容不被覆盖。
6. 手机新建笔记，应写入选择的收件目录；重复同步不应出现重复文件。
7. 关闭电脑同步后，旧配对请求应被拒绝；手机本机资料仍可编辑。重新开启并扫描新二维码恢复。
8. 导入一张图片、一段音频、一段视频；刷新后通过类型筛选打开，确认预览/播放或编码不支持提示，填写标签并搜索。导出原文件与原始文件核对内容。
9. 导入一段大于 1 GB 的视频（设备需有足够存储），确认保存进度和刷新后保留。同步途中断开 Wi-Fi，再恢复，确认续传完成，电脑收件目录中的文件与原文件字节一致，重复同步不增加副本。
10. 电脑已有图片/视频在手机打开下载后，切断网络仍可查看或导出。实际空间不足、0 字节或伪装扩展名的文件应显示具体原因，整批不导入。

## 开发与自动验证

```powershell
npm ci
npm run dev:mobile
npm run typecheck
npm run test -w apps/web
npx playwright install chromium webkit
npm run test:mobile
npm run mobile:prepare
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml
```

开发端口 5176 代理 `/api/mobile` 到本机 App 的 5177，同步仍需原生 App 明确开启。正式安装包自身提供网页，日常使用二维码中的 5177 地址。

自动浏览器测试使用合成资料和模拟同步接口，验证两种引擎的本机保存、断线编辑和冲突 UI；Rust 测试使用临时真实文件验证同位置写回、重复提交、版本冲突、路径限制和认证。模拟接口测试不等同于真机/原生 HTTP 端到端验收。

发布流程先生成签名的草稿 Release。安装包完成原生 HTTP 与真实文件往返验收后，再将该 Release 发布并设置为 latest，向正式 App 提供更新。
