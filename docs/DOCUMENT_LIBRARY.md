# 资料收件箱：使用与验收（0.2.10）

## 从哪里开始

安装 Windows 版 0.2.10 后，点击左侧 **资料收件箱**（文件夹放大镜图标），再点击 **添加监测文件夹**。此功能不需要先打开笔记库，可独立使用。每个目录都可以暂停、恢复和移除。

目录首次添加后立即扫描；App 运行时约每 30 秒检查一次，也可以点 **立即扫描**。关闭收件箱标签不影响扫描；退出 App 会停止扫描，下次启动会继续。取消“本次运行自动扫描”只对这次运行有效；目录的“暂停”状态会长期保存。

## 可以做什么

- 同时监测最多 10 个不重叠目录，包含子目录。
- 发现新增、修改、删除的文件：新增/修改进入“待整理”，删除的源文件在完整扫描后移除索引。重命名视为删除旧文件并新增资料。
- 搜索已收录的文件名、正文、摘要、分类与标签；多个空格分隔的关键词需要同时匹配。
- 查看本地正文，手写摘要、分类、标签并保存为“已整理”，也可以忽略资料。
- 使用设置中已连接的模型生成摘要、分类、标签；生成结果先展示，确认保存后才写入本机索引。
- 将已保存摘要导出为新的 Markdown 卡片，含 summary/category/tags 属性，保留来源路径。可以保存在自己的笔记库中，由原有笔记监测加载。
- App 重启后保留监测目录、索引与整理结果。磁盘断开时显示错误并保留旧索引。

## 明确的边界

- 支持 UTF-8 的 `.md .markdown .txt .csv .tsv .json .yaml .yml .xml .html .htm`，以及 `.docx` 主正文（不含图片 OCR、页眉页脚、批注等）。HTML/XML 按文本源内容收录。
- 文本/Word 解压正文上限 1 MiB；Word 压缩文件上限 20 MiB。单个超限文件不会截断伪装成完整正文，会显示“未读取正文”。
- 正文索引总量上限 16 MiB，最多 1500 个文件。每个目录扫描最多 20000 个目录项、目录遍历约 15 秒；遇到限制会给出提示并保留未确认删除的旧索引。缓慢或断开的网络盘不保证立即返回，建议选择本机资料目录。
- PDF、图片、XLSX、旧 `.doc` 等暂时仅支持文件名搜索，不支持正文提取。界面“读取提示”会列出原因。
- 跳过系统链接/目录连接、隐藏目录、缓存/构建目录和敏感名称路径。名称含“密码/账号/账户/secret/password/credential/private/token/apikey/api-key”的路径，以及 `.git .obsidian .claude .venv node_modules target dist build private-vaults vaults` 等目录不会收录。选择包含大量软件源码的上级目录通常不适合。
- 增量更新以文件大小和修改时间判断；外部程序若刻意保持二者完全不变，不会触发重新提取。
- 不自动移动、改写或删除源文件。分类是整理建议。源文件更新后，旧摘要、分类和标签失效并回到待整理。
- 本地扫描/搜索无需 AI。点击 AI 按钮才发送选中文件名和正文前 12000 字符给当前模型。AI 质量取决于模型，建议可能出错，需人工检查。
- 索引存储在 Windows 当前账户 App 本地数据目录的 `com.personal-knowledge-agent.desktop/document-library/index-v1.json`。它是本机明文资料索引，包含收录正文；不进入 Git、不会自动上传。移除监测目录会移除该目录的索引和整理结果，原文件保留；重要卡片先导出。
- 导出只新建 `.md` 文件，不覆盖已有文件。导出时会再次检查源文件是否改变。离线源文件可搜索旧索引，但不能确认保存/导出为最新整理结果。
- 网页预览显示入口与说明；文件监测在正式安装的 Windows App 使用。

## 10 分钟验收清单

可在一个专用测试目录建立下列文件，不要用重要文件测试删除或移动。

| 操作 | 预期结果 |
| --- | --- |
| 添加测试目录，目录里有 `日常.txt`，正文写“蓝鲸计划：每天学习英语二十分钟” | 待整理出现该文件，正文预览正确 |
| 搜索“蓝鲸计划”（不要写在文件名里） | 找到 `日常.txt`，说明正文索引生效 |
| 新建第二个 TXT，等待约 30 秒或点立即扫描 | 自动出现新资料 |
| 手填摘要、分类“英语学习”、标签“计划”，保存整理 | 已整理能找到它；原 TXT 内容未变化 |
| 搜索“英语学习”或标签“计划” | 找到保存的卡片 |
| 退出并重开 App，再打开资料收件箱 | 目录、已整理状态、摘要仍在 |
| 修改原 TXT 正文，立即扫描 | 新正文可搜索；旧建议清空，状态变回待整理 |
| 暂停目录，再新建文件并立即扫描 | 暂停目录没有新索引；恢复并扫描后出现 |
| 放入 PDF 或 XLSX 文件 | 读取提示中明确“暂不支持”，不显示已收录正文 |
| 在生成 AI 建议后修改源文件，再保存建议 | 提示源文件已改变，要求重新扫描；不保存过期结果 |
| 配置有效模型后点击 AI 生成建议 | 得到可编辑摘要、分类、标签；检查后再保存 |
| 未保存手写摘要时点击另一份资料 | 提示未保存内容，可继续编辑 |
| 保存整理后导出卡片到笔记库 | 新建 Markdown 文件，原资料仍在，笔记库可以打开卡片 |
| 在专用测试目录删除一个测试文件，再扫描 | 索引移除该文件；不影响其他目录 |
| 临时改名整个测试目录模拟磁盘离线，再扫描 | 显示不可访问；旧索引仍可搜索。恢复原目录名后扫描恢复 |

## 开发验证

- `npm test`：包括正文检索、AI 输入边界/输出解析、手动整理、失败提示、隐藏标签后台扫描、未保存编辑保护，以及已有功能回归。
- `npm run typecheck`、`npm run build:web`、`npm run build:desktop`。
- Windows：`cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml` 验证多目录隔离、新增修改删除、暂停、离线保留、过期建议拦截、DOCX 提取、索引完整正文、排除规则与损坏索引保护。
- 发布工作流先构建前端并执行 Rust 测试，再生成签名安装包。真实安装后的手工验收结果单独记录，不能把单元测试当成模型联网或文件选择器已验证。
