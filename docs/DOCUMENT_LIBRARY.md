# 文件知识库：使用与验收（0.3.0）

0.3.5 的电脑端默认先显示「知识卡片」；下文的原文阅读与 AI 整理操作从「原文与 AI 整理」进入。新增的离线卡片标注、共享范围、导出和回滚说明见 [电脑端知识卡片试用](DESKTOP_KNOWLEDGE_CARDS.md)。

## 日常使用

1. 打开正式 Windows App，点击左侧 **文件知识库**（文件夹放大镜图标）。
2. 点击 **添加监测文件夹**，选择你的资料目录；可以添加多个不重叠的目录。
3. 在设置中连接模型，再点击 **整理全部待处理**。每完成一份资料就保存一次，可以暂停、继续，或退出后重开。
4. 左侧按主题和子主题浏览；点击关键词筛选；切到 **知识 tip**，跨文件回顾要点并查看来源。
5. 选中资料可以修改摘要、分类、标签和 tip。分类每行一个，用 `/` 表示层级，例如 `创作/人物`；同一份资料可以同时属于 `学习/叙事`。
6. 手动改分类或标签会勾选 **保留我确认的分类和标签，AI 不覆盖**。取消此项并保存，后续 AI 才可以重新分类。
7. 需要持续整理时，打开 **自动 AI 整理新增和更新的资料**。这项偏好长期保存；暂停优先于自动整理。

这些分类是 App 的知识视图：不会为了分类移动、重命名或改写原文件。一份资料在多个分类中显示时，仍指向同一个源文件。

## 知识 tip 与来源

每条 tip 包含独立知识要点和支持它的连续原文引用。点击 **定位原文**，正文会展开并高亮引用。

AI 引用在前端和原生保存时都会进行逐字匹配；不匹配会拒绝保存。逐字匹配只验证引用存在，不能保证 AI 推论正确，仍需要核对内容。

原文件改变后，上次的摘要和 tip 会保留并提示待核对，手动确认的分类和标签保留。可以重新生成建议，或对照新原文手动修改。只调整分类时，不会把旧摘要和引用伪装成最新内容。

## 原文编辑

- **打开原文件**：用系统默认程序打开支持的文档格式。
- **编辑原文 → 保存原文**：直接修改 UTF-8 文本文件，保留原来的路径；保存前核对源版本和当前内容，并在 App 数据目录保留上次修改的撤销备份。
- **原文修改记录 → 撤销上次原文修改**：核对当前版本后恢复上一次 App 保存前的内容。
- Word、PDF、图片和 Excel 等不使用 App 的文本编辑器，避免破坏格式。
- 外部编辑器在你编辑期间保存了文件，App 会拒绝覆盖，并保留当前编辑草稿供复制或核对。

## AI 与任务边界

- 本地扫描、搜索、手动分类不调用模型。
- 点击 AI 整理或启用自动整理后，会把所选目录内支持的文件名和已收录正文发送给当前模型。正文按最多 12000 字符分段，分段有少量重叠；已收录的正文都会分析。
- 复用当前已有分类作为提示，最多保存每份资料 12 个分类、20 个标签、16 条 tip。长文摘要按段汇总并受总长度限制。
- 任务按文件逐份保存。退出或暂停时正在处理的那一份，继续后会重新分析；已完成且源版本未变的资料不会重复处理。
- 暂停会等待正在进行的模型调用返回，然后停止后续分段和保存；不会假装底层网络请求已经取消。
- 失败项保留旧结果并显示原因，通过 **重试失败项** 再试。连续 3 份失败会暂停，避免模型连接故障时继续批量请求。
- 自动扫描和 AI 队列只在 App 运行时工作；编辑资料期间暂缓后台工作。监测目录的暂停状态、AI 自动整理偏好和任务暂停状态跨重启保存。
- Agent 也能搜索、读取文件知识库，并保存虚拟知识信息；新增工具不提供移动、删除或改写源文件的能力。

## 支持范围

- 正文：UTF-8 `.md .markdown .txt .csv .tsv .json .yaml .yml .xml .html .htm`，以及 `.docx` 主正文。DOCX 不包含图片 OCR、页眉页脚、批注等；HTML/XML 按文本源内容收录。
- 文本/Word 解压正文上限 1 MiB；Word 压缩文件上限 20 MiB。正文索引总量上限 16 MiB，最多 1500 份文件、10 个不重叠目录。
- PDF、图片、XLSX、旧 `.doc` 等仍仅收录文件名并显示读取提示，不会把未读取的内容标为已分析。
- 跳过系统链接、隐藏目录、构建缓存目录和敏感名称路径，沿用既有扫描规则。
- 文件变化主要按大小和修改时间判断。外部程序若同时保持二者完全不变，不能保证发现更新。
- 完整扫描确认删除的文件后会移除对应索引；离线目录或扫描未完成时保留旧索引。目录内能够唯一匹配原内容与版本的重命名保留知识信息；无法唯一识别的情况作为新资料。
- 原文修改为普通本地文件操作，不提供对恶意程序同时替换路径的操作系统级隔离。

## 存储与迁移

索引仍在 Windows 当前账户 App 本地数据目录：

`com.personal-knowledge-agent.desktop/document-library/index-v1.json`

文件名保留以兼容旧安装位置，内部数据版本升级为 2；旧版分类、摘要与标签自动迁移。新版索引不支持回退到旧 App 直接读取。

该索引为本机明文，含正文、摘要、分类和 tip，不进入 Git，也不会随源码发布。`source-backups` 子目录保存最近一次 App 原文编辑的撤销备份。移除监测目录会移除对应索引和知识卡片，源文件保留；重要整理结果可先 **导出卡片** 为新的 Markdown 文件。

## 验收清单

请使用独立测试目录，放入两份 TXT 和一份 DOCX，不必先接入全部私人资料。

| 检查 | 操作与预期 |
| --- | --- |
| 正文检索 | 文件正文写入“蓝鲸计划”，搜索后能找到文件，文件名无需包含关键词。 |
| 虚拟多分类 | 为同一文件保存 `创作/人物` 和 `学习/叙事`。两个分类下都能找到它；原文件路径、内容不变。 |
| tip 出处 | 添加一个要点和确实存在的原文引用。保存后在知识 tip 页可查看；定位原文会高亮。 |
| 拒绝虚构引用 | 输入不存在于正文的引用，保存应失败，原来结果保留。 |
| 批量与重开 | 启动批量整理，完成一份后暂停并重开。已完成结果保留，继续只处理未完成资料。 |
| 长文末尾 | 准备超过 12000 字符的 TXT，在尾部增加独立要点。AI 应显示多段进度，生成结果包含尾部信息。 |
| 手动标签保留 | 保存手动标签并锁定，外部修改文件后扫描和再次 AI 整理。手动标签保留，摘要和 tip 可更新。 |
| 原文编辑 | 点击编辑原文并保存，原路径中文件内容变化；点击撤销上次修改能恢复。 |
| 外部冲突 | App 正在编辑时，用另一编辑器保存同一文件，再在 App 保存。应拒绝覆盖并保留 App 草稿。 |
| 失败恢复 | 模型请求失败时，显示失败项；修复连接后点击重试，成功结果逐份保存。 |
| 不支持格式 | 放入 PDF 或 XLSX，显示格式提示，不宣称已读取正文或完成 AI 分析。 |

## 开发检查

- `npm test`、`npm run typecheck`、`npm run build:desktop`、`npm run build:web`。
- Windows 原生：`cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml`。
- 签名发布工作流必须在前端和原生测试通过后构建安装包。
- 自动化测试与安装版人工验收分别记录，不把模拟模型结果当作真实模型调用成功。
