## 实际安装包验收

本机安装器退出码 0，已安装可执行文件版本为 `0.3.3`。安装包：`Agent_0.3.3_x64-setup.exe`，44,658,784 字节。

SHA-256：

```text
ac316a4b44032c2e14bd2bc2a9d0901aaccdaa423f60197d09f5b3b7a00ea31c
```

下载哈希与 GitHub asset digest 一致，更新清单中的版本、下载目标和签名文本与资产一致。安装目录包含手机页面及新增依赖许可证。

在安装后的原生 App 上，用独立的临时资料目录进行真实 HTTP 验收。测试前备份原有索引/同步配置，结束后逐字节恢复原索引，恢复原配对设置并清理测试产生的原文备份。

- 无配对密钥请求返回 401；跨站 Origin 与非局域网 IP Host 请求返回 403。
- 不存在的命令返回 404，不能通过服务读取 `mobile-sync.json`。
- 正文和分类通过 HTTP 写入，磁盘原文件内容一致，文件位置不变。
- 同一操作重复提交只确认一次，不增加重复文件或重复版本。
- 文件在电脑上外部修改后，旧版本提交返回 409，电脑新版本保留。
- 手机新笔记只写入指定收件目录，客户端路径字符串不能指定目录外的目标。
- WebKit 以 iPhone 尺寸通过实际局域网 HTTP 地址加载安装包页面，`isSecureContext` 为 false，配对、正文保存和数据库刷新正常。
- 通过手机 UI 保存后，检查磁盘文件确实变化；模拟断线保存、同时修改电脑原文、恢复连接后出现冲突对比。
- 「保留手机副本」产生一份新文件，电脑冲突版本保持原内容；刷新手机页面后资料仍存在。

本次是 Windows 上 WebKit 手机尺寸与实际原生服务的联合验收，尚不代表实体 iPhone 的键盘、后台挂起和系统回收存储行为均已验证。用户需按使用说明做一次真机配对检验。HTTP 完全离线重新打开、跨网络同步和原生 iOS 安装仍不在本版范围内。
