## 交付状态与使用边界

- 正式安装版停留在资料收件箱，可直接使用。
- 两个合成测试目录保留且已暂停；可在监测目录列表移除，原文件不会删除。
- Codex 网页预览可用于界面反馈；读取电脑目录必须使用正式 Windows App。
- App 运行时约每 30 秒检查选定目录；退出后不持续监测。
- PDF、图片、XLSX、旧 DOC 暂无正文解析；AI 整理需要有效模型连接，生成内容需自行核对。
- 扫描与搜索在本机完成；只有点击 AI 按钮才将选中文件名及正文前 12000 字符发送给当前模型。

日常操作、格式限制与逐步验收方法见 [资料收件箱使用与验收](DOCUMENT_LIBRARY.md)。
