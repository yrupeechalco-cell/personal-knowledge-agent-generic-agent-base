## 此次修复

1. **复制命令可以执行。** Windows 规范路径的 `\\?\` 前缀会使复制出的 `.cmd` 入口无法执行。现在只在提供给命令行的路径中转换为普通 Windows/UNC 写法；文件访问边界检查继续使用规范路径。
2. **兼容旧索引目录。** 文件系统比较前统一解析目录路径，保留已有资料编号和分类关联，避免普通路径与规范路径写法不同导致误判不可用或重复目录。
3. **稳定检查 TypeWords 冷启动。** CI 首次加载 2607 词词典时，原 5 秒断言曾超时。仅将该内容等待设为 20 秒，继续检查真实单词、练习流程和浏览器错误；修复后的完整构建通过。

0.4.1 在后续复制入口核对中发现问题，已收回草稿；0.4.0 也保留为历史草稿。请使用 0.4.2 或更新版本。
