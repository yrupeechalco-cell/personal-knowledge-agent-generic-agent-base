# 手机实时预览

> 0.3.3 起，小屏默认进入可持久保存和管理的手机版知识库，具体范围及验收见 [手机同步说明](MOBILE_SYNC.md)。下文记录 0.3.2 阶段的只读预览实现与历史验证，不代表当前手机版管理功能。开发地址仍使用 5176；正式安装包的手机同步使用 5177。

这是现有 Web 工作区的手机适配，用于在 Windows 上改代码、在手机 Safari 中即时检查界面。不是已经打包的原生 iOS App。Windows 正式安装包仍以 GitHub Releases 为准。

## 运行

在项目根目录安装依赖后运行：

```powershell
npm ci
npm run dev:mobile
```

终端会列出电脑当前的局域网地址，默认端口为 **5176**。手机连接同一路由器/Wi-Fi，在 Safari 中打开该地址。电脑可以通过网线接入同一路由器。不要在手机上使用 `localhost` 或 `127.0.0.1`，它们指向手机自身。

- 保持电脑开机且预览进程运行；样式和组件修改通过 Vite 热更新推送。
- CSS 修改不刷新整页，当前文档仍在；需要整页重载的改动会清空本次导入。
- 关闭服务后地址失效；重启服务仍使用 5176，电脑 IP 可能随网络变化。
- 如无法连接，确认不是访客网络/客户端隔离，且 Windows 防火墙允许 Node 的 TCP 5176 入站连接。仅需局域网连接，不需要路由器端口映射。
- 不会自动安装手机 App、建立云同步，或启动电脑上的文件扫描。

## 当前可试用的功能

- 小屏底部导航：文件、搜索、图谱、助手、更多；设置位于“更多 → 打开应用设置”。
- 可收起的文件抽屉；打开文档后自动收起，阅读区占满屏幕。
- Safari 标准文件选择器导入 `.md`、`.markdown`、`.txt`，支持多选。
- 阅读长文、全文搜索、已有标签筛选、文件双链和标签图谱。
- 界面设置和离线助手。当前 Web 适配器没有连接 Windows 的模型凭据或在线 AI 服务。

## 导入边界

- 导入的是**当前页面内存中的只读副本**，不修改、移动或上传源文件；不会保存到服务器或作为内置示例。
- 刷新或关闭网页后需要重新选择文档；这不是持久知识库，也不是电脑与手机同步。
- TXT/Markdown 扩展名在内存索引中统一为 `.md`，同名文件自动加序号；原文件不改名。
- 一次最多 50 个文件，单个不超过 2 MB，总计不超过 10 MB；沿用知识库敏感路径规则，排除项在状态栏说明。
- 暂不提供手机原目录写回、后台监听、Word/PDF 提取、在线 AI 整理或 TypeWords 手机运行环境。
- 不向手机暴露桌面端 API、电脑知识库路径或 Windows 保存的 API Key。

## 实现

共享工作区通过 `mobileLayout` 选项启用手机导航，手机样式只由 Web 入口加载，不改变正式桌面外壳。`browser-import` 来源统一走只读检查，禁止编辑和画布写回。非 HTTPS 的局域网使用 `crypto.getRandomValues` 生成兼容的消息 UUID。

`scripts/mobile-preview.mjs` 只允许访问项目路径，并拒绝 `.env`、密钥、Git 内部目录、私有知识库、`.artifacts` 本机工具、第三方源码目录和桌面原生资源。它是局域网开发服务，不是公网部署方式。

## 验收

```powershell
npm run typecheck
npm run test -w apps/web
npm run test -w packages/workspace
npm run build:web
npx playwright install chromium webkit
npm run test:mobile
```

浏览器测试使用隔离端口 18569、临时浏览器上下文和代码内测试文本，不读取用户笔记。公司代理环境需对本机地址设置 `NO_PROXY=127.0.0.1,localhost`。

2026-09-26 本机验证：

- Web 17 项与共享工作区 98 项单元/交互测试通过（包括 Agent 不能创建/改写导入副本）；类型检查和 Web 构建通过。
- WebKit（iPhone 13 尺寸）及 Chromium（Pixel 5 尺寸）共 4 项浏览器场景通过：导入、只读阅读、长文滚动、搜索、标签筛选、取消选择、图谱、助手面板、设置、320px 小屏和桌面宽度切换。
- 通过实际局域网 HTTP 地址验证两个引擎的 CSS 实时更新，未重载文档；离线助手消息 ID 正常。
- 私有工具目录请求返回 HTTP 403。
- 用户已确认真实手机能连接；首次反馈的窄条布局已定位并修复，修复后增加内容区和底栏宽度断言及截图检查。真机最新视觉效果仍以用户反馈为准。

手动检验：选择一篇文档 → 点开阅读并滚到底部 → 搜索正文中的词 → 用标签筛选 → 打开图谱 → 在电脑上改一处样式，检查手机自动更新。iOS 原生文件权限、虚拟键盘与后台行为需要后续真机专项验证。
