# 0.6.0 知识画布

知识画布改用 React Flow 12.12.0 提供选择、拖动、连接点、缩放与小地图。入口仍在左边栏，保留文本、表格、真实笔记卡片、主题分组和语义连线。

## 使用方法

1. 点「文本」「表格」创建卡片；点「笔记」选择知识库里的笔记，也可以从这个列表拖到画布上。
2. 默认「选择」模式：在空白处拖动框选；Shift/Ctrl 可多选；拖动卡片标题栏移动卡片。选中卡片后拖四角调整大小。
3. 按住空格拖动或切换「平移」移动视野；滚轮缩放；左下角按钮缩放和适应全部内容；右下角小地图可拖动定位。
4. 从卡片右侧圆点拖到另一张卡片左侧圆点建立有向关系。旧的「连线」按钮仍可用。点击连线可改为相关、支持、冲突、依赖、引用，或自定义说明。
5. 选中至少两张卡片后点「分组」。拖分组标题会一起移动成员；删除分组只解除分组，不删除成员卡片。
6. 「整理布局」按网格排开全部卡片，同时重算分组边框；不会自动推断分类或关系。可撤销。「吸附网格」让后续拖动落在整齐的位置。
7. 双击笔记卡片正文打开原笔记。卡片删除只移除画布中的引用，原笔记不删除。保存继续使用原来的本地画布保存链路。

## 数据兼容

- 持久化仍采用 `KnowledgeCanvasDocument` version 1，cards/connections/groups/viewport 的含义不变。旧内容无须用户转换，也不导入示例数据。
- React Flow 内部节点 ID 加 `card:` / `group:` 前缀防止冲突，前缀不写入持久化文档。
- CLI 的 `canvas.read` / `canvas.write` 和版本冲突检查保留。原有 Agent 通道不变。
- 一次拖动或缩放卡片记录为一次撤销；编辑文本离开输入框后记录；撤销栈只在当前画布会话中保留。编辑框内保留浏览器文字撤销行为。

## 独立运行及边界

- 桌面生产包包含 React Flow 的 JS/CSS 和开源许可，不依赖开发者电脑地址、React Flow 云服务、Node 或 Codex 来运行画布。安装环境沿用现有 Windows WebView2 要求。
- 新增依赖来自官方 npm 发布包，精确版本/完整性摘要记录在 package-lock.json；MIT 与依赖许可随安装包提供。没有使用 Pro 模板或付费示例。
- 当前资料入口是知识库笔记。Word/PDF/视频直接嵌入预览、AI 自动生成关系、多人实时协作、账户云同步不属于本次更新。
- 当前「整理布局」是卡片网格排列；没有宣称实现按关系自动分层或大规模性能提升。

## 验证与回滚

- `npm run test:canvas` 用独立的旧 v1 演示数据，在浏览器实际操作拖动、缩放卡片、连线、关系编辑、分组、撤销重做、笔记拖入、打开来源、重新载入保存结果及只读模式。
- 演示数据仅放在 scripts/canvas-fixture，测试使用独立浏览器存储，未操作用户知识库；对外网络请求被阻止以检查本地画布流程。
- 深色、浅色及窄窗口均纳入浏览器验收；GitHub 发布流水线运行相同检查并保留截图证据。
